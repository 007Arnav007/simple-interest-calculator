# Simple Interest Calculator

## Project Description

This project is a simple Bash-based calculator that calculates simple interest based on the values entered by the user.

The calculator takes the following inputs:

- Principal amount
- Rate of interest
- Time period

## Formula

Simple Interest (SI) is calculated using the formula:

SI = (P × R × T) / 100

Where:

- P = Principal amount
- R = Rate of interest
- T = Time period

Run the following command in the terminal:

```bash
bash simple-interest.sh
